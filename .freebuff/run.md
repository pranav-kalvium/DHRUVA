# DHRUVA — Preview Run Doc

Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS 4 web prototype.
Package manager: **npm** (package-lock.json present).

## Reproduce the artifacts

1. Install dependencies:
   ```
   npm install --no-audit --no-fund
   ```
2. Copy uncommitted env/artifact files from the main checkout if this is a fresh
   worktree. There are **no `.env` files** in this project (no secrets, no API
   keys; maps and route data are bundled). Files that must exist (generated,
   committed under `public/`): `favicon.ico`, `apple-touch-icon.png`, `og.png`,
   `favicon.svg`. If missing, regenerate with:
   ```
   node scripts/gen-images.mjs
   ```
3. No database, no auth, no external services at runtime. Route geometry:
   - `src/engine/data/kamshet-route.json` — real OpenStreetMap geometry for the
     Mumbai-Pune Expressway through Kamshet-1 Tunnel, generated by
     `node scripts/gen-osm-route.mjs` (needs network: Nominatim + OSRM;
     output is committed, so this is only needed if the JSON is deleted).
   - `data/iov/V-S1.csv` — IO-VNBD benchmark dataset (10.9 MB, not committed;
     download from https://github.com/onyekpeu/IO-VNBD, path
     `Synchronised V abd S datasets/.../V-S1.csv`). Required only for the
     edge-engine benchmarks, not for the app.
4. Edge engine (optional, Node): `npx tsx scripts/bench-iovnbd.mts` runs the
   IDR pipeline over IO-VNBD with a simulated 60 s outage;
   `npx tsx scripts/outage-sweep.mts` sweeps outage windows/durations.

## Run the server

```
npm run dev
```

- Dev server port: **3100** (set in `package.json` as `next dev -p 3100`).
- Dev build directory is `.next-dev` (configured in `next.config.ts` via
  `distDir`), so running `npm run build` (which writes `.next`) while the dev
  server is up is safe. Do not remove this split — sharing one dir corrupts the
  running server's CSS/chunk manifests.
- Production check: `npm run build && npm start` (also port 3100).
- Tests: `npm test` (vitest), typecheck: `npm run typecheck`.

Windows detached start (used by the preview harness):

```
powershell -NoProfile -Command "(Start-Process -FilePath 'npm.cmd' -ArgumentList 'run','dev' -RedirectStandardOutput '<log>' -RedirectStandardError '<log>.err' -WindowStyle Hidden -PassThru).Id"
```
